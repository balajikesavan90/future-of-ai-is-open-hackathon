# Python Data Analysis Agent 2.0.1

## Release preparation

This maintenance release adds an automated PyPI publishing workflow with trusted publishing, release-tag validation, and metadata consistency checks before package build and upload.

## Publishing

The GitHub release must be tagged `v2.0.1`. The publishing workflow verifies that the tag, Poetry metadata, runtime version, citation files, and Zenodo metadata all declare version `2.0.1` before it uploads package distributions to PyPI.

## Citation

The Zenodo concept DOI remains `10.5281/zenodo.18514534`. Create a new Zenodo version for this release and add its version-specific DOI to the published GitHub release notes after archival.
