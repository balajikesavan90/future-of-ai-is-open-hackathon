# Python Data Analysis Agent 2.0.0

## Major rebrand and package migration

This release renames Arctic Analytics to Python Data Analysis Agent and introduces the installable `python-data-analysis-agent` distribution.

## Migration

- Replace the former distribution with `python-data-analysis-agent`.
- Replace legacy Python imports with `python_data_analysis_agent`.
- Replace retired CLI commands with `python-data-analysis-agent` or `python-data-analysis-agent-app`.

## Highlights

- Adds resumable analysis traces for uploaded CSV workflows.
- Adds research-artifact bundle export with citation and environment metadata.
- Adds safer CSV validation, constrained execution improvements, and expanded trace validation.

## Limitations

Trace exports are not deterministic replays. Execution is application-constrained rather than OS-sandboxed, and exported traces are snapshots rather than durable audit logs.
